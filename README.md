# Library
---
## Project Overview
The City Central Library Management System is a database-driven project designed to manage library operations efficiently.  
It handles books, authors, publishers, members, loans, reservations, staff, and fines using structured SQL queries and relational database concepts.

This project demonstrates practical implementation of **DBMS concepts**, including ER modeling, table relationships, joins, subqueries, aggregation, and indexing.

---

## Objectives
- Maintain complete records of books, authors, and publishers.
- Manage library members and staff details.
- Track book borrowing, returns, reservations, and fines.
- Execute optimized queries for reporting and analysis.
- Apply indexing for better query performance.
